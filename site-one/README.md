# PhpMyTech — авторизация

Небольшое серверное приложение без внешних npm-зависимостей. Логин защищён серверной проверкой, `scrypt`-хешированием пароля, ограничением попыток, короткоживущей HttpOnly-сессией и security-заголовками.

## Быстрый локальный запуск (PowerShell)

```powershell
$env:APP_USERNAME='Nick_Name'
$env:APP_PASSWORD='придумайте-длинный-случайный-пароль'
npm start
```

Откройте `http://localhost:3000`.

## Безопасная настройка

Сгенерируйте хеш, не сохраняя пароль в репозитории:

```powershell
$env:APP_PASSWORD='ваш-длинный-пароль'
npm run hash-password
```

Скопируйте полученную строку в секрет окружения `APP_PASSWORD_HASH`, задайте `APP_USERNAME` и удалите `APP_PASSWORD`. В production приложение должно работать только за HTTPS reverse proxy; cookie автоматически получает флаг `Secure`.

После 5 неудачных попыток с одного IP вход блокируется на 15 минут. Сессия живёт 8 часов и хранится только в памяти процесса, поэтому перезапуск сервера завершает все сеансы.
